# ระบบบริหารนิติบุคคลอาคารชุด / หมู่บ้าน

โปรแกรมเว็บสำหรับนิติบุคคลคอนโดหรือหมู่บ้าน ใช้เก็บค่าน้ำ ค่าไฟ ค่าขยะ ค่าประกัน และค่าบริการอื่น ๆ
ระบบคำนวณบิลให้อัตโนมัติทุกห้อง มีระบบ login แยกสิทธิ์ผู้ดูแลระบบกับลูกบ้าน และเก็บข้อมูลย้อนหลังทั้งหมด

## ความสามารถ

**ผู้ดูแลระบบ (นิติบุคคล)**
- **ตั้งค่าวิธีคิดเงินได้เอง** ทุกรายการ แต่ละรายการเลือกวิธีคิดได้ดังนี้
  - ตามมิเตอร์ อัตราเดียว + ค่าขั้นต่ำ (ค่าเริ่มต้นค่าน้ำ: ใช้ 1-4 หน่วย เหมาจ่าย 65 บาท, 5 หน่วยขึ้นไป หน่วยละ 16 บาท)
  - ตามมิเตอร์ อัตราขั้นบันได (เช่น ค่าไฟ 0–150 หน่วย หน่วยละ 4 บาท, 151–400 หน่วย หน่วยละ 5 บาท …)
  - เหมาจ่ายต่อห้อง (ค่าเริ่มต้น: ค่าส่วนกลาง 250 บาท/เดือน, ค่าขยะ 20 บาท/ห้อง, ค่าประกัน 10 บาท/ห้อง)
  - ตามพื้นที่ห้อง (เช่น คิดค่าส่วนกลางเป็นบาท/ตร.ม. แทนก็ได้)
  - ตั้งค่าบริการบวกเพิ่ม (ค่ารักษามิเตอร์), ค่าขั้นต่ำ, VAT %
  - กำหนดความถี่ได้ (ทุกเดือน / ปีละครั้ง เลือกเดือน / ครั้งเดียว), กำหนดงวดเริ่มและสิ้นสุด
  - ใช้กับทุกห้องหรือเฉพาะห้องที่เลือก และตั้ง “ยอดเฉพาะห้อง” แทนยอดที่คำนวณได้
  - มีช่องทดลองคำนวณให้เห็นผลทันทีขณะตั้งค่า
- **เพิ่มค่าบริการใหม่ได้ไม่จำกัด** เช่น ค่าที่จอดรถ ค่าแก๊ส ค่าอินเทอร์เน็ต
- **จดมิเตอร์** เลขครั้งก่อนดึงจากงวดก่อนให้อัตโนมัติ เห็นยอดเงินทันทีหลังบันทึก รองรับมิเตอร์เปลี่ยนใหม่/วนรอบ
- **รายการเรียกเก็บเพิ่มเติม** เฉพาะห้อง/เฉพาะครั้ง เช่น ค่าซ่อม หรือส่วนลด (ยอดติดลบ)
- **ออกใบแจ้งหนี้อัตโนมัติ** ทั้งงวดในคลิกเดียว
  (ห้องที่ยังไม่จดมิเตอร์จะยังไม่ออกบิล เพื่อป้องกันบิลผิด — จดเพิ่มแล้วกดออกบิลซ้ำได้)
- **เบี้ยปรับแอดมินกรอกเอง** ที่เมนู “กรอกเบี้ยปรับ” (ตารางทุกห้องในงวด มีช่อง เบี้ยปรับ และ เบี้ยปรับค่าน้ำ)
  หรือเพิ่มในหน้าใบแจ้งหนี้แต่ละใบ ยอดบิลคำนวณใหม่ให้ทันที — เพิ่ม/แก้ชนิดเบี้ยปรับได้ที่ตั้งค่าทั่วไป
- **เลขที่ใบแจ้งหนี้/ใบเสร็จรันตามเดือนของปี** รูปแบบ `0001/10/2026` (ลำดับ/เดือน/ปี) เริ่ม 0001 ใหม่ทุกเดือน
- **ใบแจ้งหนี้และใบเสร็จรับเงิน** ดีไซน์ใหม่พร้อมโลโก้นิติบุคคล (เปลี่ยนโลโก้ได้ที่ตั้งค่าทั่วไป)
  แสดงเลขห้องเด่นชัด วันที่จด/เลขมาตรครั้งก่อน–ครั้งหลังของค่าน้ำ ยอดเงินเป็นตัวอักษร ช่องลงนาม และข้อความท้ายใบเสร็จ
  พิมพ์ A4 ได้ทั้งแบบ 1 ใบ และ 2 ใบต่อแผ่น
- **รับชำระหลายห้องในหน้าเดียว** ติ๊กห้องที่จ่ายแล้วกดบันทึก ออกใบเสร็จให้ทุกห้องพร้อมเลขที่อัตโนมัติ
- **พิมพ์ใบเสร็จทั้งงวด** ครั้งเดียว เลือกได้ 1 ใบต่อ A4 หรือ 2 ใบต่อ A4 (ประหยัดกระดาษ)
- **สร้างห้องจำนวนมากอัตโนมัติ** ระบุชั้นและจำนวนห้องต่อชั้น (เช่น 9 ชั้น × 22 ห้อง = 198 ห้อง) หรือนำเข้าจาก CSV
- **รับชำระเงิน** ทั้งแบบเต็มจำนวนและบางส่วน ออกเลขที่ใบเสร็จอัตโนมัติ พิมพ์ใบแจ้งหนี้/ใบเสร็จได้ (พิมพ์ทั้งงวดได้)
- **ยกเลิกบิล** กรณีข้อมูลผิด แล้วออกใหม่ได้ (บิลที่ยกเลิกยังเก็บไว้เป็นประวัติ)
- **รายงานย้อนหลัง** สรุปรายเดือน แยกประเภทค่าใช้จ่าย ยอดรับชำระตามช่องทาง ลูกหนี้ค้างชำระ
- **ส่งออก CSV** (เปิดใน Excel ภาษาไทยได้) และ **ดาวน์โหลดไฟล์สำรองฐานข้อมูล**
- จัดการห้อง แยก **เจ้าของห้องชุด** กับ **ผู้เช่า** พร้อมเบอร์โทรของแต่ละคน (นำเข้าหลายห้องจาก CSV ได้), ผู้ใช้งาน, ข้อมูลนิติบุคคล, รอบบิล, ค่าปรับ, ประวัติการใช้งานระบบ

**ลูกบ้าน**
- เข้าสู่ระบบดูใบแจ้งหนี้ ยอดค้าง ใบเสร็จ และประวัติการใช้น้ำ/ไฟ ของห้องตัวเองเท่านั้น
- เปลี่ยนรหัสผ่านเองได้

> บิลแต่ละใบเก็บรายละเอียดการคำนวณไว้ในตัว (ชื่อรายการ อัตรา เลขมิเตอร์) เมื่อแก้อัตราค่าบริการภายหลัง
> บิลเก่าจะไม่เปลี่ยน ข้อมูลย้อนหลังจึงถูกต้องเสมอ

## ติดตั้งและเริ่มใช้งาน

ต้องมี Python 3.10 ขึ้นไป

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

เปิดเบราว์เซอร์ที่ http://localhost:5000

- ผู้ดูแลระบบเริ่มต้น: **admin / admin123** — กรุณาเปลี่ยนรหัสผ่านทันทีหลังเข้าสู่ระบบครั้งแรก
- อยากลองด้วยข้อมูลตัวอย่าง: รัน `python seed_demo.py` ก่อน (สร้าง 12 ห้อง บิลย้อนหลัง 3 เดือน และลูกบ้าน `room101 / room101`)

ฐานข้อมูลเก็บอยู่ที่ `instance/condo.sqlite3` (ไฟล์เดียว สำรองง่าย) เปลี่ยนตำแหน่งได้ด้วยตัวแปร `CONDO_DATABASE`

ให้เครื่องอื่นในวงแลนเข้าใช้ได้: `HOST=0.0.0.0 python run.py`
จะเปิดใช้งานจริงเป็นเว็บผ่านอินเทอร์เน็ตบน Render ดูขั้นตอนที่ [DEPLOY_RENDER.md](DEPLOY_RENDER.md)

## ขั้นตอนการทำงานแต่ละเดือน

1. **จดมิเตอร์น้ำ/ไฟ** — เลือกงวดเดือน กรอกเลขครั้งนี้ (กด Enter เลื่อนไปห้องถัดไป) แล้วบันทึก
2. **รายการเรียกเก็บเพิ่มเติม** (ถ้ามี) เช่น ค่าซ่อม
3. **ออกใบแจ้งหนี้** — ตรวจความพร้อมแล้วกดออกบิล ระบบคำนวณทุกห้องให้อัตโนมัติ
4. **กรอกเบี้ยปรับ** (ถ้ามี) ให้ห้องที่ต้องเสียเบี้ยปรับ / เบี้ยปรับค่าน้ำ แล้วพิมพ์ใบแจ้งหนี้ทั้งงวด
5. **ใบแจ้งหนี้ / รับชำระ** — บันทึกเมื่อลูกบ้านจ่ายเงิน และพิมพ์ใบเสร็จ
6. ดู **รายงาน** และ **สำรองข้อมูล** เป็นประจำ

## สำหรับนักพัฒนา

```
condo/
  __init__.py        สร้างแอป, CSRF, ตัวกรองเทมเพลต
  db.py              โครงสร้างฐานข้อมูล SQLite และค่าเริ่มต้น
  billing.py         เครื่องคำนวณค่าใช้จ่ายและออกใบแจ้งหนี้
  auth.py            login / logout / สิทธิ์ผู้ใช้
  views_admin.py     หน้าจอผู้ดูแลระบบ
  views_resident.py  หน้าจอลูกบ้าน
  templates/ static/
tests/test_app.py    ทดสอบการคำนวณและขั้นตอนออกบิลครบวงจร
```

รันทดสอบ: `pip install -r requirements-dev.txt && pytest`
