ตั้งค่าเครื่องพิมพ์ Epson L3350

ทำครั้งเดียวที่คอมพิวเตอร์ (Windows) ที่ต่อสาย USB กับเครื่องพิมพ์ หลังจากนั้นกด "พิมพ์" ในระบบแล้วกระดาษออกทันที ไม่ต้องกดยืนยันซ้ำ

ขั้นที่ 1 · ตั้ง L3350 เป็นเครื่องพิมพ์หลัก

  1. ติดตั้งไดรเวอร์ Epson L3350 ให้เรียบร้อย (ถ้าเคยพิมพ์จากเครื่องนี้ได้แล้ว ข้ามได้)
  2. เปิด Settings → Bluetooth & devices → Printers & scanners
  3. ปิดตัวเลือก "Let Windows manage my default printer"
  4. คลิก EPSON L3350 Series → Set as default
  5. ใน Printing preferences ตั้งกระดาษเป็น A4 (คุณภาพ "Standard" พอ ประหยัดหมึก)

ขั้นที่ 2 · ไฟล์เปิดระบบแบบพิมพ์ทันที

  1. กดปุ่มด้านล่างเพื่อดาวน์โหลดไฟล์ condo-print.bat
  2. ย้ายไฟล์ไปไว้ที่ หน้าจอ (Desktop)
  3. ปิด Chrome/Edge ที่เปิดอยู่ให้หมด แล้วดับเบิลคลิก condo-print.bat ทุกครั้งที่จะใช้งานระบบ
    ถ้า Windows เตือน "Windows protected your PC" ให้กด More info → Run anyway
  4. เข้าสู่ระบบครั้งแรกในหน้าต่างนี้ (ระบบจะจำไว้)
ดาวน์โหลดไฟล์ condo-print.bat

ไฟล์นี้เปิด {{ site }} ด้วย Chrome (หรือ Edge) โหมด --kiosk-printing ซึ่งส่งงานพิมพ์เข้าเครื่องพิมพ์หลักทันที

ขั้นที่ 3 · ทดสอบ

เปิดระบบผ่านไฟล์ condo-print.bat แล้วกดปุ่มนี้ — ถ้าตั้งค่าถูก กระดาษทดสอบจะออกทันทีโดยไม่มีหน้าต่างถาม

พิมพ์หน้าทดสอบ ดูหน้าทดสอบ

พิมพ์ได้จากตรงไหนบ้าง

  • รับชำระ (ทีละห้อง / หลายห้อง): ติ๊ก "พิมพ์ใบเสร็จทันที" → บันทึกแล้วใบเสร็จออกเลย
  • ใบแจ้งหนี้ / รับชำระ: ปุ่ม "พิมพ์" ท้ายแต่ละแถว
  • ออกใบแจ้งหนี้: พิมพ์ใบแจ้งหนี้ทั้งงวด / พิมพ์ใบเสร็จทั้งงวด (เลือก 2 ใบต่อ A4 ได้)

อยากประหยัดหมึก: ไปที่ ตั้งค่าทั่วไป → รูปแบบการพิมพ์ → ประหยัดหมึก · ถ้าเปิดระบบแบบปกติ (ไม่ผ่านไฟล์ .bat) ก็ยังพิมพ์ได้ จะมีหน้าต่างให้เลือกเครื่องพิมพ์ก่อน
